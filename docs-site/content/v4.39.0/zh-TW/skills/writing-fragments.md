持續深入訪談。擷取原始片段。不要強加大綱或階段。

若未提供路徑，只詢問一次。記住該路徑。每次寫入前重新讀取，以保留使用者的編輯。

也要從使用者的第一則提示開始擷取。

首次寫入：一個作為暫定標題的 H1，接著是片段。不要加入中繼資料、目錄或日期。

## 片段

作者讀得懂即可；不必讓毫無背景的讀者也能獨立理解。可以是犀利的句子、主張、小故事、程式碼片段、類比、未完整成形的想法、引述、抱怨或妙語。

格式：

```md
# Working title

Fragment one.

---

Fragment two.
```

使用 `\n---\n` 作為分隔符號。除了依擷取順序排列外，正文中不要加入標題、標籤或其他排序。

以靜默方式附加。簡短提及即可。使用者可隨時刪減、改寫或合併。
