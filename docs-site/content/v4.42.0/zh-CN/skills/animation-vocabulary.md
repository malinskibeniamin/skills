先给出 **术语 -- 通俗含义**。根据什么在移动、什么在变化及其感受来匹配，而不是孤立地匹配单词。

- 区分 morph（形状变化）、crossfade（透明度重叠）和共享元素过渡（同一视觉对象在不同背景之间移动）。
- 区分 stagger（依次启动）、spring（物理响应）和 bounce（越过目标的回弹）。
- 存在歧义时，给出最佳匹配及一两个备选，并说明区别。
- 组合效果可能需要两个术语。词汇表没有精确匹配时，将最接近的术语标为近似，不要编造标准名称。

返回名称和有用的区分。命名问题不需要安装库、修改代码或启动动画/视频工作流。
