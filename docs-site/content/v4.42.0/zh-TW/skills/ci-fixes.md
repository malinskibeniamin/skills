[開啟可編輯的 Excalidraw 原始檔](/diagrams/skills/ci-fixes.excalidraw)

以更少運算資源，更快取得有意義的 CI 通過結果，同時保留迴歸保護。
最佳化從提交到最後一項必要檢查完成的時間，而不只是個別測試耗時。
遵守使用者要求的終點：稽核與計畫維持唯讀；僅在要求實作時修改。
不要順帶建立排程、購買執行器、更改分支保護或啟動代理。

## 建立基準

1. 確認目標儲存庫、分支、工作流程、可重用及複合動作、指令碼、測試設定、必要檢查和相關指引檔案。檢查實際指令。
2. 蒐集近期可比較的執行，包括失敗及重試：提交與執行連結、排隊時間、工作相依性、準備/建置/測試/上傳時間、快取狀態、執行器資源、工作程序數、分片耗時、測試數量及首次嘗試的失敗。使用平台原生日誌和報告；缺少歷史代表未知，不是速度或可靠性的證據。
3. 繪出從前置準備到最終必要結果的關鍵路徑。區分實際耗時與總執行器分鐘數及成本；記錄樣本數和環境。

## 選擇最小有效變更

完整閱讀 [CI 稽核](https://github.com/malinskibeniamin/skills/blob/v4.42.0/ci-fixes/REFERENCE.md)。評估索引中的每一項；為各適用工作記錄**採用**、**拒絕**、**延後**或**不適用**及其證據。
不要只因某種最佳化方式可用就實施。依實測關鍵路徑節省量、運算資源節省量、可信度及實作維護風險排序。
未知事項需要小規模實驗，不是捏造估算。絕不為讓工作同時結束而拖慢快速工作。

原有檢查是基礎，不是上限。相關時，依索引深入交付完整性、維運與治理。僅為尚未涵蓋的故障擴充檢查，並明確指出獨立保護的契約、可證偽的實驗、驗收訊號及負責人；重疊檢查應交叉引用，而非重複增加。更廣的診斷不授予建立服務、揭露資料或變更安全與交付政策的權限。

僅為目前工作載入輔助指引：

- 修改工作流程：[CI 維護](https://github.com/malinskibeniamin/skills/blob/v4.42.0/t3code-skills/ci-maintenance/SKILL.md)，包括其標準來源及信任邊界規則。確保憑證、快取、產物和 fork 安全。
- 精簡測試：[測試稽核](https://github.com/malinskibeniamin/skills/blob/v4.42.0/test-audit/SKILL.md)。刪除前明確指出保留的契約及其主要測試；速度和行覆蓋率本身不足以支持刪除。
- 診斷不穩定測試：[錯誤診斷](https://github.com/malinskibeniamin/skills/blob/v4.42.0/diagnosing-bugs/SKILL.md)。重現首次嘗試的失敗，修復實際實作或測試基礎設施；重試通過不等於修復。
- 升級工具：[相依套件升級](https://github.com/malinskibeniamin/skills/blob/v4.42.0/upgrade-dependency/SKILL.md)。執行時透過第一手資料確認目前穩定版本、遷移指南及執行器相容性。

實作時每次只修改一個相關瓶頸。新增行為與修復從失敗的公開契約測試開始；設定和文件使用可執行驗證，而不是搜尋指令文字的測試。保留無關變更。

## 證明改善

- 執行工作流程語法檢查、儲存庫檢查及受影響測試。驗證快取未命中、命中和失效路徑；更改測試選擇時，與完整測試集參考結果比較。驗證失敗傳遞、分片缺失及必要檢查完成狀態。
- 除了被測變數，前後基準使用相同工作負載、執行器、工具版本、工作程序數和快取條件。重複執行；報告原始耗時、樣本數、有意義的中位數和尾端情況，並分開報告執行器分鐘數及排隊時間。
- 更改工作程序、隔離或分配方式後，以擬採用的並行度重複及打亂順序執行。檢查記憶體、CPU、不穩定測試與共享狀態競爭。
- 精簡測試時，使用相同插樁、門檻、排除項目及原始碼分母，比較完整保留測試集的行與分支覆蓋率。保留獨特故障偵測能力與關鍵使用者流程，而不只是百分比；使用針對性的負向對照或變異測試。
- 執行符合變更契約的完整迴歸檢查。明確說明只能在託管環境驗證或無法驗證的部分；本機成功不能證明 GitHub CI 成功。

通過代表正確的工作確實執行了。保持錯誤可見：不吞掉結束碼，不使用 `continue-on-error`，不削弱斷言或覆蓋率，不永久跳過或隔離測試，也不用重試掩蓋不穩定測試。絕不將失敗測試移到夜間執行並宣稱已修復。

## 交接

先提供結果及其限制。包括關鍵瓶頸、索引中各項檢查的決策、前後證據及樣本與快取條件、測試契約歸屬變更和刪除理由、版本與來源確認日期、實際指令及執行連結、未解決風險和回復方式。
區分實測效益與提議實驗。詳細記錄放在儲存庫現有的證據位置；摘要重點，不要傾倒日誌。
