先給出 **術語 -- 通俗含義**。根據什麼在移動、什麼在變化及其感受來匹配，而不是孤立地匹配單詞。

- 區分 morph（形狀變化）、crossfade（透明度重疊）和共享元素過渡（同一視覺物件在不同背景之間移動）。
- 區分 stagger（依次啟動）、spring（物理反應）和 bounce（越過目標的回彈）。
- 存在歧義時，給出最佳匹配及一兩個備選，並說明區別。
- 組合效果可能需要兩個術語。詞彙表沒有精確匹配時，將最接近的術語標為近似，不要編造標準名稱。

返回名稱和有用的區分。命名問題不需要安裝函式庫、修改程式碼或啟動動畫/影片工作流程。
