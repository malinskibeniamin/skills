[Otwórz edytowalne źródło Excalidraw](/diagrams/skills/ask-ben.excalidraw)

Użyj tej umiejętności, gdy nie pamiętasz, która lokalna umiejętność pasuje do pracy Bena. Domyślnie: dostarczaj zmiany frontendowe, React, TypeScript i Go oraz wydania repozytorium umiejętności z obowiązkowym TDD, przeglądem, odpornością, dowodami wizualnymi, PR-em, CI i instalowalnymi interfejsami wtyczek.
Routing: produkt -> `/development-lifecycle`/`/work` -> `/go`; błędy -> `/diagnosing-bugs` + `/tdd`; planowanie -> `/grilling`; ogromne, niejasne zadania -> `/wayfinder` -> `/to-spec`; specyfikacje -> `/to-spec` -> `/to-tickets`; przegląd -> `/review` (dodaj `--deep` do audytów wydań); interfejs użytkownika i odporność -> `/visual-review`/`/resilience-review`; praca równoległa -> `/swarm`.
Umiejętności Builder.io są zarówno bezpośrednimi poleceniami, jak i pomocniczymi narzędziami działającymi w tle: `/visual-plan`, `/visual-recap`, `/agent-watchdog`, `/efficient-frontier`, `/plan-arbiter`, `/plow-ahead`, `/read-the-damn-docs`.
