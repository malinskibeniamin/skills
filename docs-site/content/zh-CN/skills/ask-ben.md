用于路由 Ben 的前端、React、TypeScript、Go 和技能仓库工作，包括可安装插件界面。
路由：构建 -> `/work` -> `/go`；缺陷 -> `/diagnosing-bugs`；规划 -> `/grilling`；审查 -> `/review`；庞大且模糊的工作 -> `/wayfinder` -> `/to-spec` -> `/to-tickets`。
Builder 辅助工具：`/visual-plan`、`/agent-watchdog`、`/read-the-damn-docs`。
在阶段边界阅读 [PHASE-BOUNDARIES.md](https://github.com/malinskibeniamin/skills/blob/main/ask-ben/PHASE-BOUNDARIES.md)。
