frontend-skills 工具框架将针对性指令与确定性钩子相结合，让智能体无需将整个代码库加载到上下文中，也能使用恰当的指导。

:::tip
大多数工作都从明确成果、约束条件、验证方式和最终目标开始。该工具框架仅在任务需要时选择专业指导。
:::
