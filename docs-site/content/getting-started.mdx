## Start with an outcome

State the objective, guardrails, verification, and stopping point. Use [development lifecycle](/skills/development-lifecycle) for implementation, [TDD](/skills/tdd) for a testable behavior change, and [review](/skills/review) for an evidence-backed assessment.

Check the result through the application's real entrypoint. Keep secrets out of task briefs, preserve existing work, and explicitly name any production or destructive action that needs your decision.
