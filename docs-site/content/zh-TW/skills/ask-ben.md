前端/React/TypeScript/Go 技能儲存庫；可安裝的外掛介面。
兩個日常入口：`/work <結果 + 端點>` 用於撰寫和交付；`/review <分支或 PR>` 用於唯讀評估。作者自動選擇證據、視覺化、PR 展示和交付輔助步驟，使用者不需要串聯 `/work` -> `/go`。其他命令是專用能力或相容預設。平行任務使用 `/implement-spec`，但僅限明確授權委派後。回顧使用 `/retro`。開放決定用 `/grilling`，困難缺陷用 `/diagnosing-bugs`，龐大且模糊的工作用 `/wayfinder` -> `/to-spec` -> `/to-tickets`。 [階段](https://github.com/malinskibeniamin/skills/blob/main/ask-ben/PHASE-BOUNDARIES.md)
修正錯誤後，建議使用者執行 `/retro`，了解哪些措施本可預防該錯誤；若缺少測試接縫，則建議 `/improve-codebase-architecture`。兩者均由使用者呼叫，不是自動交接步驟。
推薦或略過技能前，先閱讀其正式 `SKILL.md`；目錄僅供定位。
