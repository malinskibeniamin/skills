忘記哪個本機技能適合 Ben 的工作時，請使用此技能。預設：交付前端/React/TypeScript/Go 變更與技能儲存庫版本，並強制執行 TDD、審查、韌性驗證、視覺佐證、PR、CI，以及可安裝的外掛程式介面。
路由：產品 -> `/development-lifecycle`/`/work` -> `/go`；錯誤 -> `/diagnosing-bugs` + `/tdd`；規劃 -> `/grilling`；龐大且模糊的工作 -> `/wayfinder` -> `/to-spec`；規格 -> `/to-spec` -> `/to-tickets`；審查 -> `/review`（版本稽核請加上 `--deep`）；UI/韌性 -> `/visual-review`/`/resilience-review`；平行處理 -> `/swarm`。
Builder.io 技能既可作為直接命令，也可作為底層輔助工具：`/visual-plan`、`/visual-recap`、`/agent-watchdog`、`/efficient-frontier`、`/plan-arbiter`、`/plow-ahead`、`/read-the-damn-docs`。
