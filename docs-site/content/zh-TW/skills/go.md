從目前擁有的差異或 PR 開始，閱讀並執行[作者交付工作流程](https://github.com/malinskibeniamin/skills/blob/main/shared/delivery-workflow.md)。此預設選擇 ship：驗證、實際試用、自我審查、準備證據、發布、回報一次 CI 狀態快照，然後停止，不等待 CI、審查或核准。修復 CI、處理回饋或監控需要明確要求。保持唯一負責人。

先前明確的本機、僅提交、推送或僅草稿端點優先。`/go` 不授權合併、發布整個堆疊、整理歷史、委派、更換模型或無人值守排程。程式碼未完成時載入 [development-lifecycle](https://github.com/malinskibeniamin/skills/blob/main/development-lifecycle/SKILL.md)。
