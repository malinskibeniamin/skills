从当前所有的差异或 PR 开始，阅读并执行[作者交付工作流](https://github.com/malinskibeniamin/skills/blob/v4.40.0/shared/delivery-workflow.md)。此预设选择 ship：验证、实际试用、自审、准备证据、发布、修复 CI 并处理适用反馈，直到已验证的就绪状态。保持唯一负责人。

先前明确的本地、仅提交、推送或仅草稿终点优先。`/go` 不授权合并、发布整个堆栈、整理历史、委派、更换模型或无人值守调度。代码未完成时加载 [development-lifecycle](https://github.com/malinskibeniamin/skills/blob/v4.40.0/development-lifecycle/SKILL.md)。
