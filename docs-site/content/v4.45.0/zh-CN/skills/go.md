[打开可编辑的 Excalidraw 源文件](/diagrams/skills/go.excalidraw)

从当前自己负责的差异或 PR 开始，阅读并执行[作者交付工作流](https://github.com/malinskibeniamin/skills/blob/v4.45.0/shared/delivery-workflow.md)。验证、实际试用、自审并发布，然后执行[自动维护](https://github.com/malinskibeniamin/skills/blob/v4.45.0/shared/delivery-workflow.md#automatic-pr-maintenance)：修复 CI、反馈和冲突，验证并推送；通过一个已授权的宿主唤醒机制继续执行。

保持唯一负责人。先前的本地、仅提交、推送、仅发布或不监控停止条件优先。保留草稿状态。合并、整个堆栈的更改、委派、更换模型及持久化配置都需要相应授权范围。代码未完成时加载 [development-lifecycle](https://github.com/malinskibeniamin/skills/blob/v4.45.0/development-lifecycle/SKILL.md)。
