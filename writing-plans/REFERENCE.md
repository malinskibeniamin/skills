# Writing Plans Reference

## Self-Review Checklist

Before presenting the plan:

- [ ] **Spec coverage**: point to a task for each requirement
- [ ] **Placeholder scan**: search for TBD, TODO, "similar to", "add later"
- [ ] **Type consistency**: method names and signatures match across tasks
- [ ] **File paths**: every referenced file has an exact path
- [ ] **Commands**: every command shows expected output
- [ ] **Tests**: every implementation task has a corresponding test step

## Common Agent Excuses

| Excuse | Counter |
|---|---|
| "They'll figure it out" | Show the exact code. Don't assume context. |
| "This is obvious" | If it's obvious, it takes 10 seconds to write. Do it. |
| "Similar to Task N" | Copy the relevant parts. Don't make readers jump between tasks. |
| "Add error handling" | Show the actual error handling code, with the specific error types. |
| "TBD — needs discussion" | If it needs discussion, it's not ready for a plan. Resolve first. |
