the host's live capabilities and ownership rules take precedence. No browser,

are generated by `bash scripts/generate-skill-catalog.sh`.

[agent security guidance](https://developer.chrome.com/docs/agents/security)
on 2026-10-28. It uses object arguments, origin-scoped live descriptors, and
explicit navigation/manual-submission readback. These local corrections do not
change the pinned upstream snapshot. Recheck the evolving API during refresh.

## Refresh

Use a separate Git checkout of `BuilderIO/skills` containing the reviewed full
commit. From this repository, replace only this snapshot using:

```sh
git -C /path/to/BuilderIO-skills archive <full-commit-sha> LICENSE skills/webmcp \
  | tar -x -C vendor/builder-webmcp
```

Remove files deleted upstream from the previous snapshot. Rebuild the lock from
`git ls-tree -r <full-commit-sha> -- LICENSE skills/webmcp` and file SHA-256
digests. Preserve executable modes. Review every source file, license, linked
resource, URL, and host recipe before updating the revision here and the
independently pinned inventory digest in `evals/test-webmcp-vendored-skill.sh`.
Keep local adaptations outside the snapshot.

```sh
bash scripts/generate-skill-catalog.sh
bash evals/run.sh webmcp-vendored-skill
bash evals/run.sh packaging-integrity
bash scripts/generate-skill-catalog.sh --check
bun run lint:fix

```
