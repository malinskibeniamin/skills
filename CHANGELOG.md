2026-07-16 -- Typed protocol port, phase 2 + residual-risk fixes (same PR as phase 1). The `parse` side is now wired: hook_parse_edit_write, hook_parse_bash, and hook_adopt_stdin_session delegate scalar extraction (session_id, tool_name, file_path, command) to hook-protocol.ts when bun exists -- one bun spawn replaces the 2-3 jq spawns it covers (measured a wash: ~39ms vs ~43ms), the jq path stays as the no-bun fallback, and complex extraction (tool_input blob, apply_patch body, edits arrays) stays on jq; a parse-path parity block in Channel Contracts pins byte-identical extraction across both paths on hostile payloads (quotes, newlines, spaces in paths). The context tier is reachable and contract-correct: payloads now carry the required hookEventName (missing before -- a latent contract violation had the tier ever been wired), the CLI rejects context emits without an event name, and a new hook_context lib emitter covers it on both paths in the parity matrix (standalone context hooks stay lib-free by design). Residual risks closed: bun invocations are bounded by timeout/gtimeout where one exists on PATH (HOOK_PROTOCOL_TIMEOUT_S, default 5s, sanitized to 5 when malformed -- a bad value would otherwise exit 125 on every call and silently degrade the whole session to the shell path) so a wedged bun costs one hook seconds instead of the harness's full hook timeout -- on stock macOS without coreutils the harness hook timeout remains the only bound; resilience tests pin the crash, hang, and exit-0-with-foreign-stdout paths for both emit and parse; hook_parse_* and hook_adopt_stdin_session share _hook_input so combining them in either order can no longer read EOF; the typed-emit latency comment now states the measured ~40ms end-to-end cost instead of the optimistic ~15ms. Cross-model review findings fixed pre-commit (clean-context Claude pass: 2 P2, 4 P3; codex GPT pass: 3 P1, 1 P3): typed parse trims trailing newlines to command-substitution semantics (the jq path strips them via $(), so an end-anchored matcher would disagree across paths on byte-identical stdin); _hook_protocol_emit treats bun exit 2 as a usage error (not a contract payload) on stdout tiers and releases either contract stream only when it holds a JSON object (a shim exiting 0 with a banner, or a block tier without a JSON reason, falls back to shell instead of corrupting the live stream); hook_context skips identically on both paths when the event name is empty; _hook_protocol_parse shape-guards bun stdout before eval, checks eval status, and requires all six hp_* fields set (truncated output falls back instead of leaving unbound variables for set -u callers); HOOK_PROTOCOL_TIMEOUT_S=0 sanitizes to the default (GNU timeout 0 disables the bound entirely); the parity fixture uses mktemp -d instead of a predictable /tmp path.
