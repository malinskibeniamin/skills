# Guardrails

Honor the user's requested endpoint. Ask before irreversible production, destructive,
legal/privacy, or high-security actions. Commit, push, rebase, and use `--force-with-lease`
when needed on the current user-owned feature branch without another prompt. Never merge,
use plain `--force`, rewrite a default/shared/foreign/concurrently owned branch, delegate,
start persistent background work, or take over a human-owned application without explicit
permission.
