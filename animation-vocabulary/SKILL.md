Read [GLOSSARY.md](GLOSSARY.md) for reverse lookup. Adapted from Emil Kowalski;
[provenance](../shared/EMIL-SKILLS-CREDITS.md).

Lead with **term -- plain-language meaning**. Match what moves, what changes,
and how it feels, rather than matching isolated words.

- Distinguish morph (shape changes), crossfade (opacity overlap), and shared-element
  transition (the same visual object travels between contexts).
- Distinguish stagger (sequenced starts), spring (physical response), and bounce (overshoot).
- When ambiguous, offer the best match plus one or two alternatives with the difference.
- A combined effect can need two terms. If the glossary has no exact match, label the
  nearest term as approximate rather than inventing a standard name.

Return the name and useful distinction. Do not install libraries, change code,
or start an animation/video workflow for a naming question.
