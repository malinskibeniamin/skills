# Cloudflare security audit provenance

The complete source from [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)
is vendored unchanged at revision
[`c1c8a8c1471069fb0e188eeaff69b8e8db6564a8`](https://github.com/cloudflare/security-audit-skill/tree/c1c8a8c1471069fb0e188eeaff69b8e8db6564a8)
in [vendor/cloudflare-security-audit](../vendor/cloudflare-security-audit/README.md).
The [lock file](../vendor/cloudflare-security-audit.lock.json) records every source
path, Git blob SHA, SHA-256 digest, and executable mode.

The upstream [MIT license](../vendor/cloudflare-security-audit/LICENSE) retains
Copyright (c) 2025-2026 Cloudflare, Inc. Preserve it with the snapshot.

Only the [host adapter](SKILL.md) is registered. It resolves resources from the
vendored skill directory and preserves host delegation consent, scope, model
selection, and upstream execution safety. The Codex proxy and router entry are
generated by `bash scripts/generate-skill-catalog.sh`.

## Refresh

Use a separate checkout of the upstream repository at a reviewed full commit SHA.
Replace the snapshot with all files from `git archive <sha>`, preserving executable
modes. Rebuild the lock inventory from `git ls-tree -r <sha>` and file SHA-256
digests. Update this revision and the pinned inventory digest in
`evals/test-security-audit-vendored-skill.sh` only after reviewing the upstream diff,
license, companion paths, validators, and compatibility with the host adapter.

Run `bash evals/run.sh security-audit-vendored-skill` to verify snapshot integrity,
both plugin entrypoints, resource links, and the bundled validator test suites.
